## What this is

A faithful, browser-based reimplementation of the 1993 SSI classic
*Warlords II*. All 17 planned phases (0-16) of the original
roadmap are complete. You can play a full game end-to-end: pick a
faction, move armies across a procedural map, capture cities,
fight stack-based combat, level up heroes, recruit units, and
either capture 75 % of the cities or eliminate all enemy factions
to win.

## What ships

### Gameplay
- 32×32 procedural map with 5 terrain types (plains, forest,
  hills, mountains, water).
- BFS movement with terrain-cost weighting; per-unit move budgets.
- Stack-based combat with the 1993 attack / defense formula
  (`ATK + d6` vs `DEF + d4 + terrain_bonus`), terrain defense
  bonuses, hero stat bonuses, and Undead 20% resurrect.
- 12 unit types across 4 stat tiers (militia, spearman, archer,
  knight, cavalry, wizard, giant, …) and 1 special unit
  (**Settler**, added Phase 16).
- 8 playable factions with the full 1993 roster and unique
  bonuses:
  - **Humans** — +1 defense (Sir Marhaus)
  - **Elves** — +1 ranged attack (Lady Lorien)
  - **Orcs** — +1 melee attack (Orc Warlord)
  - **Undead** — 20% resurrect (Necromancer)
  - **Siroms** — +2 melee attack, +1 defense (Thane Korr)
  - **Dark Elves** — +1 ranged attack, +1 defense
    (Malys Shadowveil)
  - **Fey** — 10% resurrect (Queen Titania)
  - **Syrnyn** — +2 defense, +1 melee attack (King Dwalin)
- 4 hero abilities (Leadership, Fortify, Rally, Scout).
- City capture, per-turn income, production queue, mines, ruins,
  armories.
- A* pathfinding, defend/expand/attack AI strategy.
- Win conditions: 75% city capture or last-faction-standing.
- Save / load via `localStorage`.

### Visuals
- **Original 1993 Warlords II screenshots** as in-game backdrops
  for the menu, world map, combat, hero, production, and quest
  dialogs (Phase 14).
- **Original 1993 HUD chrome** (top menu bar, right command
  panel, bottom action bar) cropped from the 1993 world-map
  reference and used as DOM backgrounds (Phase 15).
- **16-color Warlords-II palette** read byte-exact from the
  original `STANDARD.PAL`; strict exact-match test enforces it.
- 1993-styled VICTORY! and DEFEAT overlay scenes with marble +
  gold panels and Pope attribution (Phase 16).

### Audio
- 7 music tracks (menu, faction-select, gameplay, combat,
  victory, defeat, ambient pad) generated via the project's
  music pipeline.
- 10 SFX stings (sword, arrow, magic, move, recruit,
  city-capture, victory, defeat, click, error).
- Mute toggle in the top bar; URL flags `?mute=1`, `?music=0`,
  `?sfx=0`.

## Known issues & limitations

- **Settler "found city"** — the Settler unit is in the roster,
  but the click-to-found-city handler is not yet wired. Tracked
  for a future phase.
- **Real 1993 per-faction hero portraits** — currently the
  placeholder `humans.png` is reused for all 8 factions. The
  real 1993 portraits live in the floppy's `DATA/*.DAT` files
  and require extraction. Tracked.
- **Real 1993 per-faction city fortresses** — currently the
  neutral fortress is reused for all 8 factions. The 1993 game
  has 8 distinct fortress designs in `PICS/*.PCK`. Tracked.
- **Roads and coastline** — not yet rendered between adjacent
  tiles. Tracked.
- **Dependabot PR #11** is open (Vite 5→8, Vitest 2→5). Major
  version bumps; the github-steward agent will validate and
  recommend merge or close.
- The clone is **not** affiliated with SSG, Ubisoft, or Steve
  Fawkner.

## Verifying the release

```bash
git clone https://github.com/LegendaryLionMan/warlords2-clone.git
cd warlords2-clone
git checkout v1.0
npm install
npm run dev   # http://localhost:5173
```

…or run the full validation suite:

```bash
npm run typecheck && npm run lint && npm test && npm run build
npm run e2e    # needs `npm run dev` running in another shell
```
