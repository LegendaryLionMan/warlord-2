## What this is

**Warlord 2** is an original turn-based strategy game inspired by
the 1990s 4X wargame tradition. All 17 planned phases (0-16) of
the development roadmap are complete. You can play a full game
end-to-end: pick a faction, move armies across a procedural map,
capture cities, fight stack-based combat, level up heroes,
recruit units, and either capture 75 % of the cities or eliminate
all enemy factions to win.

Warlord 2 is built from scratch — code, art, music, lore, and
names are all original. The visual language is "1990s 4X
wargame" but no protected material from any specific historical
game is shipped. This project is not affiliated with, endorsed
by, or associated with SSG, Ubisoft, or any other rights holder.

## What ships

### Gameplay
- 32×32 procedural map with 5 terrain types (plains, forest,
  hills, mountains, water).
- BFS movement with terrain-cost weighting; per-unit move budgets.
- Stack-based combat with the classic `ATK + d6` vs
  `DEF + d4 + terrain_bonus` formula, terrain defense bonuses,
  hero stat bonuses, and Undead 20% resurrect.
- 12 unit types across 4 stat tiers (militia, spearman, archer,
  knight, cavalry, wizard, giant, …) and 1 special unit
  (**Settler**).
- 8 playable factions with unique bonuses and lore:
  - **Humans** — +1 defense (Sir Marhaus)
  - **Elves** — +1 ranged attack (Lady Lorien)
  - **Orcs** — +1 melee attack (Gor Ironfist)
  - **Undead** — 20% resurrect (Lord Vryx)
  - **Siroms** — +2 melee attack, +1 defense (Thane Korr)
  - **Night Elves** — +1 ranged attack, +1 defense
    (Malys Shadowveil)
  - **Fey** — 10% resurrect (Queen Titania)
  - **Syrnyn** — +2 defense, +1 melee attack (King Dwalin)
- 4 hero abilities (Leadership, Fortify, Rally, Scout).
- City capture, per-turn income, production queue, mines, ruins,
  armories.
- A* pathfinding, defend/expand/attack AI strategy.
- Win conditions: 75% city capture or last-faction-standing.
- Save / load via `localStorage`.

### Visuals
- **Original AI-painted sprites** for terrain, cities, features,
  units, and hero portraits (Phase 12). One sprite per
  (unit, faction) combination.
- **Original hand-coded 16-colour pixel art** for terrain tiles,
  city fortresses, units, hero portraits, and UI chrome (Phase 13).
- **Procedural marble + gold backdrops** for the menu, world
  map, combat, hero, production, quest, and outcome scenes
  (Phases 14-16) — all rendered from Phaser Graphics primitives.
- **CSS-only chiseled-stone HUD** (top bar, right panel, bottom
  action bar) — no image assets.
- 16-colour Warlord 2 palette inspired by the 1990s SVGA
  16-colour tradition.

### Audio
- 7 original music tracks (menu, faction-select, gameplay,
  combat, victory, defeat, ambient pad) generated via the
  project's music pipeline.
- 10 original SFX stings (sword, arrow, magic, move, recruit,
  city-capture, victory, defeat, click, error).
- Mute toggle in the top bar; URL flags `?mute=1`, `?music=0`,
  `?sfx=0`.

## Asset credits

All in-game art, music, and SFX in Warlord 2 are original. The
visual style is inspired by the 1990s 4X-wargame tradition but
no asset is a copy, extraction, or modification of any specific
historical game. Sprite art was generated from text prompts
authored for this project; music and SFX were generated from
scratch. See `docs/asset-credits.md` for the full generation
pipeline and prompt samples.

## Known issues & limitations

- **Settler "found city"** — the Settler unit is in the roster,
  but the click-to-found-city handler is not yet wired. Tracked
  for a future phase.
- **Per-faction hero portraits** — currently a single placeholder
  human portrait is reused for all 8 factions until distinct
  original portraits are drawn.
- **Per-faction city fortresses** — currently the neutral
  fortress is reused for all 8 factions. Distinct fortresses
  are planned.
- **Roads and coastline** — not yet rendered between adjacent
  tiles. Tracked.
- **Dependabot PR #11** is open (Vite 5→8, Vitest 2→5). Major
  version bumps; the github-steward agent will validate and
  recommend merge or close.

## Verifying the release

```bash
git clone https://github.com/LegendaryLionMan/warlord-2.git
cd warlord-2
git checkout v1.0
npm install
npm run dev   # http://localhost:5173
```

…or run the full validation suite:

```bash
npm run typecheck && npm run lint && npm test && npm run build
npm run e2e    # needs `npm run dev` running in another shell
```
