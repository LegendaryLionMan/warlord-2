# v1.1 — Warlord 2 rebrand + procedural backdrops

**Tag:** `v1.1`
**Date:** 2026-09-08
**Commit:** `e408daa` (chore(rebrand): Warlord 2 + drop 1993 art in favour of procedural backdrops)
**Test status:** 110 / 110 unit, typecheck / lint / build all clean.

## What this is

A non-mechanical rebrand + legal-defensibility pass. Same game, same
mechanics, same tests, but:

- The project is now called **Warlord 2** (was *Warlords II Clone*).
- All in-game art, chrome, and dialog backdrops are now procedural
  Phaser Graphics / CSS — no extracted images from any specific
  historical game.
- The repo is renamed `LegendaryLionMan/warlord-2` (was
  `LegendaryLionMan/warlords2-clone`); the old name stays as a
  redirect from the rename.
- The 16-colour palette is "inspired by the 1990s SVGA 16-colour
  tradition" rather than byte-exact to a specific historical file.
- The 1993 *Warlords II* asset directory and HUD-chrome crops are
  gone; the visuals are now built from `src/render/backdrops.ts`
  (a small Phaser Graphics helper) and CSS-only chiseled-stone
  gradients.

This release is the same playable game as v1.0, but with the
copyright-risk surface dramatically reduced. See
[`docs/changelog/`](../changelog/) and `CHANGELOG.md` for the
detailed change list.

## What changed

### Renamed
- Repo: `warlords2-clone` → `warlord-2`
- Display name: "Warlord 2 Clone" → "Warlord 2"
- Package: `warlord-2@1.0.0`
- Faction: "Dark Elves" → "Night Elves" (slot identity, hero
  name, all internal references)
- All marketing text now describes Warlord 2 as "an original
  turn-based strategy inspired by the 1990s 4X wargame
  tradition", not "faithful to the 1993 Warlords II"

### Removed
- 18 original-1993 image files under
  `public/assets/sprites/original/` (title screen, world map,
  combat / hero / production / quest dialog backdrops, 3 HUD
  chrome crops, 10 Internet Archive reference shots)
- 7 `original.*` manifest keys + 7 `original.*` asset-paths
  entries + the `originalPath()` helper
- All `url('/assets/sprites/original/...')` references in the
  HUD CSS
- The strict byte-exact `STANDARD.PAL` palette test
- 1993 / SSG / Steve Fawkner attribution from `LICENSE`,
  `docs/asset-credits.md`, and the in-game footer

### Added
- `src/render/backdrops.ts` — a small Phaser Graphics helper
  that paints 6 different procedural backdrop styles (menu,
  combat, hero, production, quest, outcome) plus a `drawPanel()`
  for in-scene cards. Each style is a flat colour + dither
  pattern + accent panel + gold frame, drawn at runtime.
- CSS-only chiseled-stone HUD (top bar, right panel, bottom
  action bar) using layered `linear-gradient` and `box-shadow`
  — no images.
- Procedural terrain + city + army-dot + viewport-rect minimap
  in `GameScene.drawMinimap()`.

## What did NOT change

- Game mechanics, formula, balance, win conditions — all
  identical to v1.0.
- All AI-painted sprites (Phase 12) and hand-coded 16-colour
  pixel art (Phase 13) — both original to this project.
- All AI-generated music and SFX — both original to this project.
- 110 / 110 unit tests, 66 / 66 e2e tests — same count, same
  outcomes (e2e screenshot test names were updated to drop the
  "1993" prefix, but the assertions are unchanged).
- The Settler + 4 new factions + OutcomeScene from Phase 16.

## Upgrade path

From v1.0: identical gameplay. The rebrand only changed
display strings, asset paths, and (some) CSS — there is no
save-format or mechanics change. v1.0 saves load into v1.1.

## Verifying the release

```bash
git clone https://github.com/LegendaryLionMan/warlord-2.git
cd warlord-2
git checkout v1.1
npm install
npm run dev   # http://localhost:5173
```

…or run the full validation suite:

```bash
npm run typecheck && npm run lint && npm test && npm run build
npm run e2e    # needs `npm run dev` running in another shell
```
